# SOUBEL Content Page Hero Standard

Date: 2026-09-16
Status: Review standard for internal content/repository pages.

## Purpose
Prevent page-by-page visual drift in masthead, hero background, eyebrow size, title scale, lead copy, margins, and spacing.

## Standard opening pattern
1. SOUBEL masthead
2. Canonical primary navigation
3. White hero background
4. Teal uppercase eyebrow
5. Dark H1 at controlled content-page scale
6. One muted lead paragraph

## Typography and spacing
- Eyebrow: approximately 0.88rem desktop
- H1: clamp(2.2rem, 3.15vw, 3.05rem)
- H1 max width: 980px
- Lead: approximately 1.03rem, max width 960px
- Hero padding: 42px top / 36px bottom desktop
- No manual H1 line breaks unless required by meaning
- No redundant breadcrumb when the eyebrow already identifies the page
